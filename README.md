# Sales Performance MIS Dashboard (Excel)

An interactive Excel-based MIS dashboard designed to analyze sales performance, profitability, customer contribution, payment behavior, and regional trends. This project transforms raw sales data into meaningful business insights using PivotTables, PivotCharts, KPI cards, slicers, and professional dashboard design techniques.

---

## Project Objective
- Analyze monthly sales and profit trends
- Identify top-performing product categories and states
- Monitor business profitability using KPI metrics
- Understand customer contribution and purchasing behavior
- Analyze payment mode preferences
- Build an interactive dashboard for management reporting and decision-making

---

## Dataset Structure
**File Name:** 'Sales Dataset.csv'

| Column Name  | Description               |
| ------------ | ------------------------- |
| Order ID     | Unique order identifier   |
| Amount       | Total sales amount        |
| Profit       | Profit earned from sales  |
| Quantity     | Quantity of products sold |
| Category     | Product category          |
| Sub-Category | Product sub-category      |
| PaymentMode  | Customer payment method   |
| Order Date   | Date of order placement   |
| CustomerName | Customer name             |
| State        | State of order            |
| City         | City of order             |
| Year-Month   | Monthly grouping field    |

## Business Insights Generated
- Office Supplies category generated the highest revenue.
- December recorded peak sales and profit performance.
- Texas contributed the highest state-wise sales.
- Customers preferred digital payment methods over COD.
- A small group of customers contributed significantly to total revenue.
